# Domains — Function Discovery Views

**Status:** draft. Domains are **selection/navigation views**, not distinct enterprise schemas. Pick multiple domains if the organization spans several.

| Domain group | Available domain views |
|---|---|
| Commerce | [Retail and E-commerce](function-matrix.md#retail-and-e-commerce); [Wholesale and Distribution](function-matrix.md#wholesale-and-distribution) |
| Production and Construction | [Manufacturing](function-matrix.md#manufacturing); [Construction](function-matrix.md#construction) |
| Professional and Field Services | [Professional Services](function-matrix.md#professional-services); [Equipment and Field Maintenance](function-matrix.md#equipment-and-field-maintenance) |
| Care and Education | [Health Care Clinics](function-matrix.md#health-care-clinics); [Education and Training](function-matrix.md#education-and-training) |
| Finance | [Insurance](function-matrix.md#insurance); [Financial Services](function-matrix.md#financial-services) |
| Membership and Public Benefit | [Nonprofit Membership Association](function-matrix.md#nonprofit-membership-association); [Charity and Foundation](function-matrix.md#charity-and-foundation); [Religious or Community Organization](function-matrix.md#religious-or-community-organization); [Government and Public Services](function-matrix.md#government-and-public-services) |
| Travel, Property and Hospitality | [Hospitality and Travel](function-matrix.md#hospitality-and-travel); [Property Management](function-matrix.md#property-management) |

See [domain-to-function mappings](function-matrix.md). Each view lists suggested canonical function names; users may select any function from the [full catalog](../business-functions/functions.md). A domain label is contextual terminology, not evidence of a different underlying function.

The mapping is intentionally **not exhaustive**. AI should ask what the enterprise actually does and invite additions rather than assuming unchecked functions are irrelevant.

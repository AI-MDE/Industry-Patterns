# Administration

Administration contains the reusable structures used to operate an organization regardless of industry.

It is not an industry domain. Industry profiles select Administration concepts rather than redefining organization, workforce, facilities, or accounting concepts.

## Areas

- [Organization](organization/README.md)
- [Human Resources](human-resources/README.md)
- [Facilities](facilities/README.md)
- [Accounting](accounting/README.md)

## Boundary

Administration describes the internal machinery of an organization.

- **Organization** — organization units, departments, positions, reporting structure, and locations.
- **Human Resources** — workers, employment, jobs, skills, competencies, qualifications, and position requirements.
- **Facilities** — sites, facilities, buildings, spaces, workplaces, and facility assignments.
- **Accounting** — accounts, ledgers, receivables, payables, invoices, expenses, and settlement.

Industry domains should reference or specialize these concepts instead of copying them.

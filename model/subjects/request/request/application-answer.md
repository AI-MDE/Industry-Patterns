# Application Answer

Subject: [Requests, Quotes, and Orders](../README.md). ABE: [Request](README.md).

Also known as: Intake Response (Physical Therapy).

## Definition and detail

A recorded response to an underwriting question or required declaration.

Logical attributes: Answer Identifier; Question Code; Answer Value; Answer Date; Answered By; Source; Verification Status.

### In industries

- **Intake Response** (Physical Therapy): A Patient- or representative-supplied response to a clinic question. Attributes: Response Identifier; Question Code; Response Value; Recorded Date; Respondent; Source; Verification Status.

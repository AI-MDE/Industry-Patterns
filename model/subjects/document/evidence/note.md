# Note

Subject: [Documents and Evidence](../README.md). ABE: [Evidence](README.md).

Also known as: Clinical Note (Health Care), Claim Note (Insurance).

## Definition and detail

A versioned clinical narrative authored in a declared context.

Logical attributes: Note Identifier; Note Type; Note Status; Authored At; Author; Encounter reference; Version; Supersedes Note reference.

### In industries

- **Claim Note** (Insurance): A versioned narrative record of significant Claim activity or reasoning. Attributes: Claim Note Identifier; Note Type; Note Status; Authored At; Author; Text; Supersedes Note Reference.

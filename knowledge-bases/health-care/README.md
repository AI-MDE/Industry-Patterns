# Health Care Knowledge Base

This is a metamodel-conformant MDE knowledge base generated from the [Health Care model pattern](../../patterns/health-care.md).

It follows the [MDE metamodel](https://github.com/AI-MDE/mde/tree/main/method/metamodel) and keeps independently meaningful capabilities, entities, use cases, workflows, rules, and roles in separate semantic files.

## Scope

This is a reusable **Standard** Health Care knowledge base, not a complete hospital system and not a jurisdiction-specific regulatory implementation. Applications select and specialize the relevant knowledge.

## Canonical model

This knowledge base is a selected application projection of the [coherent industry model](../../model/README.md). Its Entity pages link to their canonical origins while retaining their selected attributes, operations, states, and rule references. Canonical model integration does not discard application-specific detail.
